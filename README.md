# Temporary measurement repo (v25 kernel)

Temporary public repo created only to run the CurveSmash v25 lane-kernel
measurement on a native ARM GitHub Actions runner. It contains only the
v25 `measure/` package, the organisers' `scripts/reference_costs/`
harness, and the workflow that runs `measure/reproduce_lanes.sh`.

This repo is not a submission and will be deleted after the measurement
run. No credentials or keys are stored here.
